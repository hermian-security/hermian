apt.hermian.me

Hermian, kept current
by apt.

Signed packages for Debian and Ubuntu. Add the repository once and apt upgrade updates Hermian like any other package. Every download is checked against the key below.

latest @VERSION@amd64 · arm64Debian · Ubuntued25519 signed
The easy way

→One command

Installs the package, checks it against the release's signed SHA256SUMS, and adds this repository for you.

install
$ curl -fsSL https://github.com/hermian-security/hermian/releases/download/@VERSION@/install.sh | sudo sh
Or by hand

01Add the signing key

/usr/share/keyrings
$ curl -fsSL https://apt.hermian.me/hermian-archive-keyring.gpg \
    | sudo tee /usr/share/keyrings/hermian-archive-keyring.gpg >/dev/null

02Add the repository

beta gets every prerelease; switch to stable once v0.1.0 is out.

/etc/apt/sources.list.d/hermian.sources
$ sudo tee /etc/apt/sources.list.d/hermian.sources >/dev/null <<'EOF'
Types: deb
URIs: https://apt.hermian.me
Suites: beta
Components: main
Signed-By: /usr/share/keyrings/hermian-archive-keyring.gpg
EOF

03Install

apt
$ sudo apt update && sudo apt install hermian
$ sudo hermian status

Suites

betaprereleases and releases
@BETA@
stablereleases, from v0.1.0
@STABLE@

Verify the key

Its fingerprint, which every release also prints in its build log:

@FINGERPRINT@
gpg
$ gpg --show-keys /usr/share/keyrings/hermian-archive-keyring.gpg

Each release ships the same hermian-archive-keyring.gpg in its signed SHA256SUMS.

Remove

uninstall
$ sudo hermian uninstall

Or sudo apt purge hermian. Both remove the repository entry and the key too.
