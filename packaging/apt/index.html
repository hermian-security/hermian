github.com/hermian-security/hermian

APT repository

Signed Debian and Ubuntu packages. Add it once and apt upgrade keeps Hermian current, like any other package.

latest @VERSION@amd64 · arm64Debian · Ubuntusigned with ed25519
THE EASY WAY

→Use the one-line installer

It installs the package, checks it against the release's SHA256SUMS, and adds this repository for you.

curl -fsSL https://github.com/hermian-security/hermian/releases/download/@VERSION@/install.sh \
  | sudo sh
OR BY HAND

01Add the signing key

curl -fsSL https://apt.hermian.me/hermian-archive-keyring.gpg \
  | sudo tee /usr/share/keyrings/hermian-archive-keyring.gpg >/dev/null

02Add the repository

Use beta for every prerelease, or stable once v0.1.0 is out.

sudo tee /etc/apt/sources.list.d/hermian.sources >/dev/null <<'EOF'
Types: deb
URIs: https://apt.hermian.me
Suites: beta
Components: main
Signed-By: /usr/share/keyrings/hermian-archive-keyring.gpg
EOF

03Install

sudo apt update && sudo apt install hermian
sudo hermian status
SUITES
SUITEGETSNOW
betaEvery prerelease and release@BETA@
stableReleases only, from v0.1.0@STABLE@
VERIFY THE KEY

apt checks every download against this key. Its fingerprint, which every release prints in its build log:

@FINGERPRINT@ 
gpg --show-keys /usr/share/keyrings/hermian-archive-keyring.gpg

Each release also ships hermian-archive-keyring.gpg, listed in its signed SHA256SUMS: compare the two if you like.

REMOVE
sudo hermian uninstall        # or: sudo apt purge hermian

Both remove the repository entry and the key too.

Silent by default. Loud when it matters.
